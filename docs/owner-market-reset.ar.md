# المسح الشامل متقاعد

قسم `/admin/maintenance` أصبح للمراقبة والقراءة فقط بناءً على قرار المالك.
أزيلت منه أزرار التنظيف والحذف وإعادة ضبط السوق، وأزيل SQL المسح من المكتبة.

طلبات التنفيذ والمعاينة القديمة تُرفض بـ`403 maintenance_read_only` حتى مع
تفعيل متغيرات سابقة أو إرسال رموز معاينة محفوظة. لا يوجد متغير لإعادة تشغيلها.
لا تحاول إصلاح هذا الرفض بتعطيل فحص الصلاحية أو الرجوع إلى إصدار يسمح بالمسح.

اختبارات `owner-market-reset` تحتفظ بالاسم للتحقق من منع المسار المتقاعد:
تفحص صلاحيات HTTP والرفض قبل قراءة الحمولة أو الاتصال بقاعدة البيانات.
اختبار PostgreSQL الاختياري يقرأ بصمات الجداول قبل المحاولة وبعدها ويثبت عدم
تغير البيانات؛ لا ينفذ مسحًا تجريبيًا ولا ينشئ أو يحذف قواعد.

راجع [مراقبة الصيانة والنسخ](recovery-console.ar.md) للتصميم الحالي وصلاحيات
القراءة فقط. تنفيذ الاستعادة يتم خارج التطبيق من AWS بهوية تشغيل مستقلة.
