# إيقاف واجهات الصيانة والتنظيف

أزيلت صفحة `/admin/maintenance` ومكوّنات تصفح قاعدة البيانات والتنظيف وإعادة ضبط السوق من لوحة الإدارة. تبقى صفحة العمولات ووظائفها دون تغيير، وتُدار رسالة الموقع من صفحة المالك `/admin/site-message`.

المسار القديم `/api/admin/maintenance` محتفظ به لإرجاع استجابة آمنة للروابط والعملاء القدامى فقط: `401` لغير المسجل، و`403` لغير المالك، و`410` للمالك. لا ينفذ هذا المسار قراءة أو تعديلًا لقاعدة البيانات أو التخزين.

هذا الإيقاف لا يحذف بيانات قاعدة البيانات أو ملفات Cloudflare، ولا يغير مخطط قاعدة البيانات أو مهام تنظيف الصور الخلفية. كما تبقى سجلات التدقيق التاريخية كما هي.
