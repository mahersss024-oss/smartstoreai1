# الترحيل والرجوع

- نقطة الرجوع المحلية `audit/hamad-pre-refactor-20261122` تشير إلى خط الأساس قبل التغييرات. الفرع `refactor/hamad-specialized-20261122` يحتفظ بالتجربة.
- `SMARTSTORE_HAMAD_STRUCTURED=0` هو الوضع الافتراضي. التشغيل التجريبي المعزول يتطلب القيمة `1`. تفعيلها لدى بيانات أو مزودي إنتاج يتطلب موافقة.
- لتعطيل التجربة، أعد المفتاح إلى `0` وطبّق إعداد السيرفر. الطلبات اللاحقة تستعمل خط الشات السابق. يعامل قارئ الذاكرة السابق رمز التجربة المشفر كسياق جديد، وتبقى المسودات محفوظة في المستودع.
- `KEEP` لبوابات API والوسائط والحفظ ومصادر المنصة المشتركة. `REPLACE` لمسار فهم النية والحقول داخل الوضع التجريبي. `REMOVE AFTER VERIFICATION` لمحددات العبارات القديمة وأجزاء التوافق التي يثبت عدم استعمالها بعد انتهاء فترة الرجوع.
- لا تُحذف الأكواد القديمة في هذه الدفعة. عقد API والواجهة الحالية ومسار النشر العام باقية على نسختها.
