# الترحيل والرجوع

- نقطة الرجوع المحلية `audit/hamad-pre-refactor-20261122` تشير إلى خط الأساس قبل التغييرات. الفرع `refactor/hamad-specialized-20261122` يحتفظ بالتجربة.
- اعتمد فرع `refactor/hamad-structured-only` المنسّق الجديد مباشرة على `POST /api/chat`. انتهى استخدام مفتاح `SMARTSTORE_HAMAD_STRUCTURED` مع حذف مسار الحوار القديم.
- الرجوع بعد نشر الكود، إن لزم، يتم باستعادة مراجعة سيرفر سبق اختبارها. لا توجد ترحيلات قاعدة بيانات لهذه الدفعة. تبقى المسودات المحفوظة قابلة للفتح من «إعلاناتي»، وقد يلزم اختيار المسودة مجددًا عند انتقال المحادثة من رمز الذاكرة السابق.
- يحافظ المسار على بوابات API والوسائط والحفظ ومصادر المنصة المشتركة. البطاقات خيار إضافي للإصدارات التي تدعمها، والإصدارات السابقة تستقبل القائمة النصية.
