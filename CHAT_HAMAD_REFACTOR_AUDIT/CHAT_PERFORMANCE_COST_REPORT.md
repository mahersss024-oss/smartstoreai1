# الأداء والتكلفة

الرد يحافظ على نقل SSE. زمن أول نص ظاهر وزمن اكتمال البث يقاسان في فحص محلي مصطنع. أحداث `hamad_structured_role` تسجل زمن الدور واستهلاك الإدخال والإخراج المتاح ضمن استدعاءات الحوار والتحقق والصياغة. سجل `hamad_capability` يضيف اسم القدرة والمدة حتى للخطوات التي لا تستدعي نموذجًا. الاستدعاءات الداخلية للأدوات المشتركة لها أدلتها التابعة للمزود.

| المرحلة | الأدوار المتوقعة |
| --- | --- |
| صفحة مسودات | دور الخطة ثم استعلام المالك. |
| إكمال أو قراءة | دور الخطة حسب الحالة، ثم حقائق القراءة وصياغة موثوقة. |
| كتابة | خطة وتحقق كتابة وإيصال، ثم رد متحقق. تضاف معالجة تصنيف ناقص عند اللزوم. |
| سؤال منصة | خطة واسترجاع حتى مصدرين وصياغة وتحقق رد. |
| صورة | الدور البصري المشترك فقط للملفات المحددة. |

قاس الفحص المحلي 30 رسالة مباشرة إلى المسار مع مزوّد اصطناعي، عند المراجعة `482dc47`. سجل القياس في `coverage/hamad-structured/performance-summary.json`.

| القياس | p50 | p95 |
| --- | ---: | ---: |
| وصول أول نص ظاهر | 7.60 مللي ثانية | 40.35 مللي ثانية |
| اكتمال بث الرد | 7.98 مللي ثانية | 40.95 مللي ثانية |

سُجل 65 استدعاءً للأدوار النصية. اكتمل 64 منها، وأُوقفت محاولة واحدة في سيناريو انتهاء المهلة. أعاد المزود الاصطناعي 768 رمز إدخال و512 رمز إخراج. قيمة التكلفة الفعلية غير مقاسة، وكذلك استهلاك الرؤية والمراجعات الداخلية للأدوات المشتركة. قياس الجودة والسرعة والتكلفة في ظروف الاستخدام الفعلي يتطلب تجربة معتمدة على مزوّد حقيقي.
