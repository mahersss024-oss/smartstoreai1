# سجل القدرات

جميع المداخل المسجلة تتضمن اسمًا ووصفًا ومخطط إدخال ومخرج Zod قابلًا للاستخراج بصيغة JSON Schema، وحالة الإصدار والتمكين، وصلاحية الجلسة، والأثر، وسياسة التكرار، والمهلة، وضبط سجل المراجعة. يفحص `run` الحقول عند الدخول والخروج ويرفض أثر الكتابة دون حجز عملية. تبقى أسماء القدرات معروفة مسبقًا في السيرفر.

| القدرة | الأثر | التنفيذ الموجود |
| --- | --- | --- |
| `list_my_drafts` | قراءة | `listSellerListings` عبر هوية الجلسة، ثم صفحة من أربعة عناصر. |
| `get_draft` | قراءة | `getListing` بعد قيد المالك والحالة الإدارية. |
| `create_draft` | كتابة مسودة | `createMarketplaceTools().createListingDraft`، مع مفتاح لإعادة الطلب. |
| `update_draft` | كتابة مسودة | `updateListing` بمرجع مملوك وقيم شاهدة. |
| `attach_draft_images` | إضافة صور | `addUploadedImagesToListing` للملفات المحددة والشاغرة. |
| `get_categories` | قراءة | كتالوج التصنيفات المشترك. |
| `get_platform_info` | قراءة | فهرس مصادر `getPlatformHelp` العامة. |
| `analyze_image` | قراءة | المراجعة البصرية الموجودة للملفات المؤهلة. |

التسجيل من مراجعة الكود. الصلاحيات محصورة بقراءة بيانات الحساب المسموح بها وإنشاء المسودات وتعديلها وتحليل الصور واسترجاع المعلومات العامة. [التنفيذ ومخططات Zod](../lib/chat/hamad-capabilities.ts)

ملف القياس المحلي `coverage/hamad-structured/capabilities.json` يحتوي على مخططات JSON Schema المستخرجة للقدرات الثماني.
